# Transfer Nightscout 15 V1-V3 data to LibreView
Transfer your diabetes data from Nightscout to LibreView. 
Support Nightscout 15.
Support V1 and V3 data.

## Requirements
- git
- nodejs
- dont try to upload more than 90 days 

## First use

Open command line in your favorite folder:
```
git clone https://github.com/Pyyton2025/nightscout-to-libreview.git
cd nightscout-to-libreview
npm install
npm start
```

## Future use

Open command line in your favorite folder:
```
cd nightscout-to-libreview
npm start
```
